## 0. 一句话

每个 Pixel 的诞生都是一次**抽卡仪式**：八维属性在 0.5–2.0 之间随机 roll 点，定出稀有度与词条；人物来历三选一（阁主钦点 / GitHub 访贤 / 千机随机）；再按属性与经历自动拼出独一无二的人物卡形象 prompt 并生成卡面图。从此每个 Pixel 都是一名有数值、有来历、有脸的鲜活「千机」。

## 1. 背景与目标

- 现状：此前运行出的几个 Pixel 与「千机阁」故事已无法承接。
- 已执行（2026-09-28）：本地数据全部清空，从零开始（见 §6）。
- 目标：重建人物生成体系，让**每一个 Pixel = 一个鲜活角色**，且整套流程自带传播属性（抽卡实况、人物卡都是可发布的素材）。

## 2. 世界观承接：甲子重开

- 故事包装：千机阁「甲子重开」，旧事不清算、不解释，直接开启新纪元。阁主（用户）亲手抽出第一批千机。
- 英灵殿机制保留：今后试炼落选 / 退役的千机入英灵殿归档，形成可追溯的「阁史」。只进不出，不可篡改。

## 3. 核心系统一：八维属性抽卡

### 3.1 属性定义

8 维，取值范围 **0.5–2.0**，保留 1 位小数。**1.0 = 常人基准线**。

| 字 | 属性名 | 含义 | 高值表现（≥1.6） | 低值表现（≤0.7） |
|---|---|---|---|---|
| 谋 | 谋略 | 目标拆解、计划制定 | 算无遗策 | 想到哪做到哪 |
| 察 | 洞察 | 信息捕捉、读懂人心与市场 | 明察秋毫 | 后知后觉 |
| 决 | 决断 | 风险之下拍板的速度与胆识 | 当机立断 | 优柔寡断 |
| 行 | 执行 | 落地推进、按时交付 | 雷厉风行 | 拖延空转 |
| 言 | 交涉 | 谈判说服、转化成交 | 舌战群儒 | 讷于言 |
| 创 | 创意 | 新点子、破局能力 | 天马行空 | 墨守成规 |
| 韧 | 韧性 | 逆境恢复、长期主义 | 百折不挠 | 一触即溃 |
| 学 | 学识 | 知识储备、学习速度 | 博闻强记 | 现学现卖都慢 |

设计理由：8 维覆盖一个 AI 组织做生意需要的全部能力象限（想 / 看 / 断 / 干 / 谈 / 创 / 熬 / 学），且每维高低都有叙事张力（低谋是莽夫、低言是社恐——缺陷即人物弧光素材）。

### 3.2 抽卡算法

- 每维独立 roll 点：`v = clamp(round1(1.0 + gauss(μ=0, σ=0.28)), 0.5, 2.0)`
- 用正态分布而不用均匀分布：大多数人落在 0.8–1.2（平庸大多数），极端值稀有，SSR 才有「抽中」的快感。
- 每次抽卡记录随机种子 `seed`，结果可复现、可审计。

### 3.3 稀有度（综合 = 8 维均值）

| 稀有度 | 阈值 | 称号 | 期望概率 |
|---|---|---|---|
| SSR | ≥ 1.65 | 天纵奇才 | 约 3–5% |
| SR | ≥ 1.35 | 出类拔萃 | 约 15% |
| R | ≥ 1.05 | 中流砥柱 | 约 45% |
| N | < 1.05 | 璞玉待琢 | 约 35% |

### 3.4 词条系统（叙事燃料）

- 任一维 **≥1.8** → 「天赋·X」（如「天赋·谋」），写入人物亮点。
- 任一维 **≤0.6** → 「短板·X」（如「短板·言」），写入人物缺陷。
- 词条直接驱动人设文本与卡面神态（见 §5），保证「数值—叙事—形象」三位一体。

### 3.5 保底与仪式感

- 十连保底 SR：连续 9 次未出 SR 及以上，第 10 次强制 SR 保底（计数器存 DB）。
- 前端设「观星台」抽卡页：点击抽卡 → 星轨动画 → 翻牌揭示，稀有度决定揭示特效（SSR 全屏星屑）。

## 4. 核心系统二：三种人物生成模式

统一管线：**抽卡（属性）→ 定叙事（三种来源）→ 生成形象 prompt → 入阁**。

三种模式只在「叙事来源」不同，属性一律照抽（钦点也不许定属性，保证抽卡公平性——这是规则铁律）。

### 模式 A：阁主钦点

- 输入：姓名（可空→从姓名池随机补）、职位、一句话人设（如「话少、算无遗策的老军师」）。
- AI 按指定扩写：完整小传、缺陷、行为指令、口头禅。
- 若 roll 出的属性与钦点人设严重冲突（如钦点"神机妙算"却谋=0.5），**保留冲突**——冲突即戏剧性，写入人物小传（"世人皆道他算无遗策，只有阁主知道他的谋略全靠熬夜"）。

### 模式 B：GitHub 访贤

- 输入：职位（如「跑商」）。
- AI 到 GitHub 搜索该职位相关的技能与项目（如 trading bot、议价话术库、出海营销工具），提取 3–5 个技能标签。
- 按技能标签生成人物：姓名、经历（"曾师从 XX 项目"）、擅长；技能标签与 repo 链接存入人物「师承」字段。
- 铁律：只引用**真实存在**的 repo（附链接），不编造项目名。搜不到就降级为模式 C 并注明。

### 模式 C：千机随机

- 全随机：姓名池（古风姓氏 × 单/双字名）、职位池（军师 / 跑商 / 工匠 / 说客 / 账房 / 斥候 / 医官 / 司晨……）、小传模板（"曾是{前尘}，如今{今朝}"）。
- 属性照抽。纯盲盒，适合快速扩充阁中人口。

### 数据结构（qianji profile 扩展字段）

```json
{
  "attributes": { "谋": 1.8, "察": 1.6, "决": 1.1, "行": 0.9, "言": 0.6, "创": 1.2, "韧": 1.0, "学": 1.3 },
  "rarity": "SSR",
  "traitTags": ["天赋·谋", "短板·言"],
  "origin": "appointed | github | random",
  "lineage": ["https://github.com/xxx/yyy"],
  "seed": 20260928,
  "cardPrompt": "…形象 prompt 全文…",
  "cardImage": "workspace/live/portraits/{pixel_id}.png"
```

## 5. 核心系统三：人物卡片图像

### 5.1 统一风格锚（成套感，不可改）

新中式玄幻 × 全息科技：水墨人物、悬浮符箓与数据流、暗色阁楼背景、卡片构图、电影光。

英文风格锚（给生图模型用，固定前缀）：

> Neo-Chinese fantasy × holographic tech, ink-wash character portrait, floating glowing talismans and data streams, dark pavilion interior background, trading card composition, cinematic lighting, ultra detailed

### 5.2 Prompt 模板

```
{style_anchor},
character: {appearance ← 年龄/性别/体态，取自叙事},
attire: {服饰 ← 职位 + 最高属性，查映射表},
prop: {手持物 ← 最高属性，查映射表},
expression: {神态 ← 缺陷/性格，查映射表},
background: {意象种子 ← 最高两属性组合，查映射表} with {经历关键词 ← 小传/师承},
color theme: {主色 ← 最高属性，查映射表},
{rarity_frame}, {rarity_effect}
--ar 3:4
```

### 5.3 映射表（实施时补全）

- **主色**：谋=玄青、察=银白、决=赤红、行=赭金、言=紫、创=青绿、韧=墨黑、学=月白
- **服饰/道具**（职位 × 最高属性）：军师+谋→羽扇纶巾；跑商+言→算盘锦囊；斥候+察→斗篷千里镜；工匠+创→机关匣；账房+学→算筹书卷……（按职位池 × 8 属性补全）
- **意象种子**（最高两属性组合，共 28 种）：谋+察=棋局星图；言+决=惊堂木与远方商队；创+学=书山与机关鸟；韧+行=栈道与孤灯……（28 组全部定义，不许复用）
- **神态**（←缺陷/短板）：短板言→欲言又止、手指轻叩；短板决→眉头微蹙、反复掂量手中物；天赋谋→眼含星河、似笑非笑……
- **稀有度边框**：N=无边框素卡；R=铜边；SR=银边+流光；SSR=金边+星屑环绕特效

### 5.4 唯一性规则（硬性）

1. prompt 指纹 = hash(属性向量 + 意象种子 + 经历关键词 + seed)，存档备查；
2. 同一「最高属性组合」的人物，意象种子池内轮换、**不许重复**（抽卡时检查，已用种子跳过）；
3. prompt 全文存入 `profile.cardPrompt`——可复现、可审计，呼应千机阁「不可伪造」原则。

### 5.5 存储与 MVP 策略

- 图片落盘：`workspace/live/portraits/{pixel_id}.png`；
- MVP 允许先只生成 prompt 文本占位（卡面显示"待绘"），图片异步补齐，不阻塞抽卡主流程。

## 8. 与事件营销的衔接

- 抽卡实况本身就是内容：「阁主十连抽」「首张 SSR 诞生！」天然适合短视频/直播切片。
- 每张人物卡 = 可发帖素材：属性面板截图 + 小传 + 卡面图，一人一帖。
- 稀有度天然制造话题与追更：「下一张 SSR 何时出」。
- 事实/叙事分离铁律：属性是随机数（事实），小传是 AI 写作（叙事），对外发布时明确标注，不虚构战绩与收入。
